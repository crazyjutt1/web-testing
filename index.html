Formats Guide

Understanding colour formats

A quick reference for the formats the Colour Picker outputs, and when to reach for each one.

HEX

A six-digit code like #5B4FE8, the most common way the Colour Picker's result is used in CSS, HTML and design software.

RGB & RGBA

Red, green and blue channels from 0–255, with an optional alpha channel. The Colour Picker outputs both automatically.

HSL

Hue, saturation and lightness — often the easiest way to nudge a colour lighter, darker or more muted with the Colour Picker.

HSV

Hue, saturation and value, close to how many colour wheels and paint mixers describe colour, mirrored by the Colour Picker.

CMYK

Cyan, magenta, yellow and key (black), an approximation the Colour Picker calculates for print-facing work.

Choosing a format

For the web, use HEX or RGBA from the Colour Picker; for print layouts, start from the CMYK approximation instead.
